# NahaAdmin - Free Bootstrap 5 Admin Dashboard

![NahaAdmin Banner](assets/images/banner.png)

NahaAdmin adalah template admin gratis yang bersih, modern, dan sepenuhnya responsif yang dibangun menggunakan **Bootstrap 5**, vanilla JavaScript, dan CSS. Proyek ini menyediakan fondasi kokoh serta komponen antarmuka pengguna untuk membangun aplikasi web, backend SaaS, atau panel dasbor.

## 🚀 Live Demo & Dokumentasi
* **Live Demo:** [naha-admin.vercel.app/demo/](https://naha-admin.vercel.app/demo/) *(atau URL hosting Anda)*
* **Dokumentasi:** [naha-admin.vercel.app/docs/](https://naha-admin.vercel.app/docs/)

---

## ✨ Fitur Utama
* **Bootstrap 5:** Desain bersih, mudah disesuaikan, dan modern.
* **Beragam Pilihan Dasbor:**
  * Dasbor CRM
  * Dasbor Analitik
  * Dasbor E-Commerce
  * Dasbor Keuangan
* **Tipografi & Ikon Menarik:** Menggunakan Google Fonts (Outfit & Inter) dan **Phosphor Icons**.
* **Animasi Transisi & Loading:** State pemuatan halaman yang halus menggunakan **NProgress** serta animasi masuk lewat **Animate.css**.
* **Komponen UI Lengkap:** Tombol, kartu, modal, dropdown, alert, progress bar, dan form (termasuk editor, select, validasi, dan tata letak check).
* **Penyajian Data:** Tabel yang sudah terkonfigurasi rapi menggunakan Grid.js dan DataTables.
* **Optimasi SEO:** Dilengkapi meta tag SEO dan Open Graph bawaan.
* **Ramah Developer:** Struktur folder yang rapi dan konfigurasi Vercel yang siap pakai.

## 📁 Struktur Folder
```text
naha-admin/
├── assets/
│   ├── images/       # Aset gambar bersama (logo, banner, favicon)
│   ├── plugins/      # Pustaka pihak ketiga (Bootstrap, Phosphor, NProgress, dll)
│   ├── scripts/      # Skrip kustom (naha-admin.min.js & skrip spesifik halaman)
│   └── styles/       # Stylesheet kustom (naha-admin.min.css & gaya spesifik halaman)
├── demo/             # 53+ Halaman HTML siap pakai
├── docs/             # Situs web dokumentasi statis
├── index.html        # Halaman Landing utama
├── robots.txt        # Konfigurasi perayap mesin pencari
└── sitemap.xml       # Daftar indeks mesin pencari
```

## 🛠️ Panduan Memulai & Pengembangan Lokal

Karena NahaAdmin adalah template statis yang dibangun dengan HTML, CSS, dan JS, Anda tidak memerlukan proses instalasi yang rumit. Anda bisa menjalankannya secara lokal menggunakan cara berikut:

### Opsi 1: Buka Langsung di Browser (Paling Mudah)
Cukup klik dua kali berkas `index.html` di direktori utama untuk membukanya langsung di browser web Anda.

### Opsi 2: Menggunakan VS Code Live Server
1. Buka proyek ini di **VS Code**.
2. Instal ekstensi **Live Server**.
3. Klik tombol **Go Live** di pojok kanan bawah VS Code.
