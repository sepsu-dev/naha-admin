Getting Started

A free, open-source admin dashboard template licensed under MIT. It is a clean suite of HTML, CSS, and JavaScript files built on top of Bootstrap 5.3 — not a bloated framework, not an npm component library. You drop it into your project, customize the markup to suit your application, and ship.

No build tools or bundlers are required! NahaAdmin is built with vanilla HTML, CSS Custom Properties, and modular JavaScript. You can serve it directly with any local static HTTP server (like VS Code Live Server, npx serve ., or php -S localhost:8000).

NahaAdmin is built natively on Bootstrap 5.3.x. It leverages Bootstrap 5.3's modern utility classes, CSS Custom Properties, and responsive flexbox components.

NahaAdmin's core layout mechanics, sidebar toggling, and page transitions are written in pure vanilla JavaScript. However, jQuery is included in assets/plugins/jquery/ so you can seamlessly use plugins like DataTables, Select2, or legacy scripts without conflicts.
Framework Integrations

  1. Copy the assets/ directory into your framework's public directory (e.g. public/ for Laravel/PHP or static/ for Django/Flask).
  2. Extract the top navigation bar, sidebar navigation, and footer from demo/starter.html into your template layout or blade partials.
  3. Render your dynamic server-side content directly inside the <main id="layoutSidenav_content"> container.
Customization & Theming

Simply modify the --nd-primary CSS variable inside assets/styles/naha-admin.css (or assets/styles/docs.css). All buttons, active sidebar links, focus rings, and badge accents will update instantly across all pages.

Apply the class nd-nav-fixed to the <body> tag for fixed top navbar behavior, and nd-sidenav-toggled to collapse the sidebar into the mini-mode rail (which auto-expands on hover).

Add target="_blank" or specific data attributes to your anchor tags, or remove the click intercept handler in assets/scripts/naha-admin.js.
