Browser Support

Modern browser requirements and validation scope.

Target current stable Chrome, Edge, Firefox, and Safari on desktop, plus current Chrome on Android and Safari on iOS/iPadOS. Bootstrap 5.3 provides the base, but template-specific CSS and browser APIs can need newer browsers.

See Bootstrap browser guidance for the underlying framework. It is not a test report for this template. Internet Explorer and legacy Edge are not supported.

AreaRequirements and limits
Theme and layoutCSS custom properties, Grid, Flexbox, color-mix(), and OKLCH colors. Older engines may drop declarations; no legacy-browser polyfill bundle is included.
Popover and context menuNative Popover API; use a current browser. A Bootstrap modal is not a fallback for these demos.
Sidebar and focusModern inert support keeps hidden navigation out of keyboard focus. localStorage saves desktop preference; blocked storage disables persistence, not toggling.
Files and clipboardFile selection and attachment previews stay local. Clipboard access can need HTTPS or localhost and browser permission. No upload service is provided.
External assetsGoogle Fonts, CDN plugins, map tiles, and remote images may require a connection and compatible content security policy. Bundled libraries remain local.

Validation scope

The checks in CONTRIBUTING.md cover local references, asset consolidation, JS syntax, and an icon-search regression. CI runs these static and mocked-DOM checks, not a browser suite. Review pages manually at 1440, 390, and 320 px; emulated widths are not physical-device tests. No Safari, Firefox, or Edge certification is claimed.

There is no Browserslist configuration or transpilation step in this repository. Before release, test your selected pages in target browsers and real touch devices, including zoom, keyboard focus, reduced motion, and blocked network/storage. See Getting Started for checks and FAQ for troubleshooting.
