Theme & Layout

CSS variables, custom color tokens, and layout modes.

1. Global CSS Custom Properties

NahaAdmin uses CSS Custom Properties defined in assets/styles/naha-admin.css for global theming. After editing, copy its contents to assets/styles/naha-admin.min.css, the compatibility copy loaded by the examples. The soft light palette combines cool neutral surfaces, charcoal text, and a muted teal accent. Semantic tokens such as --background, --foreground, --primary, --secondary, --muted, --accent, --destructive, --border, --input, and --ring feed the NahaAdmin and Bootstrap aliases.

Variable Default Value Description
--nd-primary #386b65 Primary actions; focus uses the separate ring token
--nd-bg-light #f5f7f8 Global dashboard background color
--nd-surface #ffffff Card and navbar background color
--nd-border #dfe6e7 Border color for dividers, tables, and card outlines
--nd-text #293638 Base primary heading and typography color 
:root {
  --primary: #386b65;
  --primary-foreground: #ffffff;
  --ring: #648d87;
  --radius: 0.625rem;
  --nd-primary: var(--primary);
  --nd-primary-rgb: 56, 107, 101;
  --nd-primary-light: #56877f;
  --nd-primary-dark: #2e5954;
}

Bootstrap utilities, buttons, and links use these tokens. Dashboard charts keep a separate categorical palette. Primary and destructive badges use solid fills; secondary uses a neutral fill. Status colors retain their meaning, with pale backgrounds and readable foregrounds. Categorical charts use six muted colors rather than status colors for unrelated data. Outfit is shared across the landing page, documentation, dashboards, and charts, with system fonts as a fallback. Keep brand hex values and their RGB aliases in sync. Vendor themes may need separate edits. This template ships a light theme; a complete dark theme is not included.

2. Layout Modes & Classes (Apply to <body>)

Fixed Navbar (nd-nav-fixed)

Pins top navigation bar to the top of the viewport during scrolling with smooth shadow separation.

Mini Sidebar (nd-sidebar-mini nd-sidenav-toggled)

Collapses the sidebar to an icon-only rail (70px) on desktop. It expands on hover or keyboard focus without shifting content. Without nd-sidebar-mini, toggling hides the sidebar.

3. Sidebar State Persistence

Desktop sidebar state is saved in localStorage under nd|sidebar-toggle. If storage is blocked, toggling still works without persistence. On mobile, the sidebar starts closed; Escape closes it and returns focus to the toggle. Crossing the desktop breakpoint resets the visible state.
