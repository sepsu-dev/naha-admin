Modern Admin Dashboard Built with Bootstrap 5

NahaAdmin is a clean, modern, and lightweight open-source admin template. Built on top of Bootstrap 5, it provides a comprehensive range of responsive, reusable, and commonly used UI components for your web applications.

Core Features

Why Developers Choose NahaAdmin

A modern, production-ready foundation designed to help you build fast, responsive, and beautiful web applications.

Built on Bootstrap 5

Harness Bootstrap 5.3 utility classes, modern CSS variables, and a responsive grid system with zero unnecessary bloat.

Flexible Layout Styles

Includes standard fixed navigation, collapsible sidebar, mini sidebar, and fluid drawer navigation that adapt seamlessly across devices.

Extensive UI Kit

Packed with ready-to-use buttons, cards, modals, tabs, alerts, badges, breadcrumbs, and interactive form elements for rapid prototyping.

1,000+ Phosphor Icons

Pre-configured with over 1,000+ crisp Phosphor bold vector icons that scale crisply on Retina and high-density screens.

Pre-built App Pages

Includes essential ready-to-use application templates such as Inbox, Chat, Kanban Board, Authentication, and Error pages.

100% Free & Open Source

Distributed under the permissive MIT license. Completely free to use, customize, and deploy in personal, client, or commercial projects.
