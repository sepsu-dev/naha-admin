Introduction

Overview and core philosophy of NahaAdmin.

Naha Admin is a free Bootstrap 5 admin template built with HTML, CSS, and jQuery. Start from an example, reuse the components, and connect your own backend.

Run it locally

Double-click index.html in the project folder to open it in your browser. No local server, package installation, or build step.

Open the demo or landing page directly. Need the files? Follow the setup guide.

What's included

5 dashboards, 4 app examples, and 66 component examples, plus combined form demos. Browse them from the Components menu in Live Preview.

Examples use sample data, not a live backend. Check the FAQ, get support, or review the MIT license.
