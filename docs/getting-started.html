Getting Started

Installation, local setup, and folder structure.

Follow the simple steps below to set up and run NahaAdmin on your local machine.

1. Cloning the Repository
git clone https://github.com/sepsu-dev/naha-admin.git
cd naha-admin
2. Local Run (Avoid CORS Issues)

Since the template utilizes modular JavaScript and dynamic AJAX elements, we recommend running it via a local development server rather than double clicking HTML files directly:

  • VS Code: Install the Live Server extension, right-click index.html, and select Open with Live Server.
  • Node.js / npx: Run npx serve . in your terminal.
  • PHP Built-in Server: Run php -S localhost:8000 in the project root.
3. Creating New Pages (Blueprints)

To build new views, duplicate one of our clean pre-configured templates inside demo/:

demo/starter.html

Contains header navbar, sidebar navigation, footer, and a starter container ready for your custom widgets and cards.

demo/blank.html

Minimal page scaffolding with empty canvas, suitable for bespoke application modules and custom views.

4. Folder Structure
naha-admin/
├── assets/         # App assets (CSS, JS, images, icons)
│   ├── plugins/    # Third-party libraries (Bootstrap 5.3, Simplebar, ECharts, DataTables, etc.)
│   ├── scripts/    # Main custom JS (naha-admin.js)
│   └── styles/     # Core styling & variables (naha-admin.css)
├── demo/           # 53+ Pre-designed dashboard and application pages
├── docs/           # Standalone multi-page documentation
└── index.html      # Landing & introduction page
5. Plugins & Vendors Reference

All third-party libraries are bundled under assets/plugins/ for offline and self-hosted reliability:

Plugin Purpose Directory
Bootstrap 5.3 Core UI grid, modals, alerts, utilities assets/plugins/bootstrap/
Phosphor Icons 1,000+ vector icon set (Bold, Regular, Fill) assets/plugins/phosphor/
SimpleBar Custom lightweight scrollbar for sidebars assets/plugins/simplebar/
NProgress Slim progress bar for page transitions assets/plugins/nprogress/
DataTables & Grid.js Interactive tables with search & sorting assets/plugins/datatables/, gridjs/
