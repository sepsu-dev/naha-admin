Introduction

Welcome to NahaAdmin! NahaAdmin is a clean, modern, premium, and fully responsive free admin template built with **Bootstrap 5**, vanilla JavaScript, and customized CSS layout engines. It is designed to provide a highly flexible workspace canvas for building admin portals, SaaS dashboard management consoles, and data visualization platforms.

Core Project Features:
  • Modern Tech Stack: Fully integrated with Bootstrap 5, jQuery, ECharts, SweetAlert2, and Tempus Dominus without relying on heavy frontend framework overhead.
  • SPA-Like Experience: Integrated page transition mechanisms using NProgress loading overlays and smooth element fade animations.
  • Sleek Design System: Clean HSL primary brand accents, Outfit & Inter typography pairings, modern card layouts, and responsive mini sidebar hover setups.
  • MIT License: Open-source, developer-friendly, and free to use for personal or commercial projects.

Installation & Setup

Getting started with NahaAdmin is simple. You can download the pre-packaged files or clone the repository directly from GitHub to begin your project development.

Download the latest release ZIP file from the GitHub repository, extract it to your preferred workspace directory, and you are ready to go.

Folder Structure

NahaAdmin is organized to separate template assets, third-party libraries, live demo files, and developer documentation:

naha-admin/
├── assets/               # Static assets shared across the application
│ ├── images/           # Site logo, avatars, banners, and default icons
│ ├── plugins/          # Vendor assets (Bootstrap, Phosphor, Simplebar, ECharts, Select2)
│ ├── scripts/          # Custom scripts (naha-admin.js, page-specific modules)
│ └── styles/           # Global styles (naha-admin.css, page-specific views)
├── demo/                 # Complete suite of 53+ pre-designed HTML pages
├── docs/                 # Documentation static website files
├── index.html            # Main landing page for marketing / entrance
├── robots.txt            # Search engine optimization directive rules
├── sitemap.xml           # Sitemap index for indexing pages
└── vercel.json           # Routing and clean-URL rules for Vercel deployment

Use the files in the demo/ directory as reference blueprints. Duplicate demo/blank.html or demo/starter.html whenever starting a fresh web application workspace page.

Customizing Theme Styles

NahaAdmin is built using CSS Custom Properties (Variables), making theme customization extremely fast and simple. You can override colors, typography, borders, and margins globally inside your CSS stylesheets.

Defining Variables (Inside :root)

The variables are declared in assets/styles/naha-admin.css. You can customize them directly or redefine them in a separate overrides stylesheet:

:root {
  /* Brand Theme Colors */
  --nd-primary: #006fee;          /* Main color for brand identity & active links */
  --nd-primary-light: #3e94ff;    /* Hover accents and soft highlights */
  --nd-primary-dark: #005bc4;     /* Darker states for hover/active focus */
  --nd-success: #10b981;          /* Confirmation and success tags */
  --nd-danger: #ef4444;           /* Errors, alerts, and deletion prompts */
  --nd-text: #11181c;             /* Global base body text color */
  --nd-text-muted: #71717a;       /* Secondary descriptions and labels */
  --nd-border: #e4e4e7;           /* Border color for tables, cards, lines */

  /* Component Layout Values */
  --nd-radius: 10px;              /* Standard radius for buttons/inputs */
  --nd-radius-lg: 16px;           /* Larger radius for primary cards/modals */
  --nd-transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);
}

Tip: Always use relative paths when adding a separate customized stylesheet to avoid breaking assets on different folder depth levels.

Dashboard Layout Customization

Modify the layout and navigation structures quickly by managing CSS class toggles on the primary <body> element of your documents:

Class Toggle Applied On Description & Function
nd-nav-fixed <body> Forces the top navigation brand header to stay fixed at the top of the browser viewport during page scroll.
nd-sidenav-toggled <body> Collapses the sidebar on screens > 992px, or brings it into viewport view on screens < 992px (responsive).
Sidebar Mini Mode (Auto-Expand on Hover)

Applying the class nd-sidenav-toggled on screens wider than 992px collapses the sidebar accordion list items down to an icon-only representation. When a user hovers their mouse pointer over this mini sidebar area, the menu container smoothly expands to full width via modern CSS transitions, allowing convenient navigation access without taking up permanent canvas workspace.

Sidebar & JavaScript Architecture

The user interface handles state persistence and page transitions dynamically to deliver a fast application-like experience.

Sidebar State Persistence

When a user toggles the sidebar using the collapse button, the selection is saved inside the browser's localStorage under the database key: nd|sidebar-toggle. On subsequent page loads, NahaAdmin reads this key immediately and applies the configuration classes, preventing content layout shifts.

Smooth Page Transitions (Multi-Page App)

NahaAdmin features page fade-out and fade-in animations on navigation. When an internal anchor link is clicked, the script intercepts the event, triggers the NProgress loading bar, fades out the content viewport using the animate__fadeOut transition, and redirects the browser window after 350ms once the animation concludes.

Excluding Links from Fade Transitions

To bypass this behavior (e.g. for files, external pages, modal openers, or dropdown components), make sure the anchor tag contains any of the following features: target="_blank", data-bs-toggle="...", or has an href starting with #, http, or javascript:.

Adding a New Workspace Page

Creating a new view within the NahaAdmin workspace follows a straightforward workflow:

  1. Clone Template: Copy demo/blank.html or demo/starter.html and save it with your desired file name (e.g. demo/new-dashboard.html).
  2. Add Page Content: Open the file and locate the main structural viewport wrapper: 
    <main>
    <div class="container-fluid px-4">
        <!-- Insert your charts, tables, or custom forms here -->
    </div>
</main>
  3. Update Sidenav Link: Find the sidebar markup container inside the HTML file and append a link tag pointing to your new file: 
    <a class="nav-link" href="new-dashboard.html">
    <div class="nd-nav-link-icon">
        <i class="ph-bold ph-chart-bar"></i>
    </div>
    <span>New Statistics</span>
</a>
  4. Highlight State: The active highlight status on your newly created menu links will automatically be handled on page initialization by our dynamic active routing script.

Phosphor Icons Usage Guide

NahaAdmin relies on the modern Phosphor Icons pack, providing a fresh style for UI layouts.

Style Variations
  • Bold Icons: Add the class prefix ph-bold (recommended for clean navigation links).
  • Solid/Filled Icons: Add the class prefix ph-fill (recommended for warnings, user states, or active buttons).
HTML Code Examples
<!-- Bold Icon -->
<i class="ph-bold ph-house-line"></i>

<!-- Filled Icon -->
<i class="ph-fill ph-house-line"></i>

Dynamic Active Route Highlighting

You do not need to manually write `.active` classes on each separate HTML file template when users navigate between pages.

The system automatically processes active routes using JavaScript on startup. The routing engine performs the following actions:

  • Reads the browser URL pathname through window.location.pathname.
  • Identifies and selects matches against the href attributes of the links within the navbar or sidebar accordions.
  • Applies the active class modifier to the matching link to highlight it.
  • Walks up the DOM hierarchy tree to automatically open any nested parent menu panels (applying the show class) to reveal the location path.
