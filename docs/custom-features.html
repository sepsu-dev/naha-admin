Custom Features

Built-in JavaScript enhancements and utility helper classes.

1. Page Transitions & NProgress

NahaAdmin automatically intercepts internal page navigations to display a top progress bar and smooth content fade. To exclude specific links (such as downloads, external URLs, modals, or tab toggles), apply any of these attributes:

<!-- Excluded automatically from SPA transition: -->
<a href="https://example.com" target="_blank">External Link</a>
<a href="#modalId" data-bs-toggle="modal">Open Modal</a>
<a href="javascript:;">JS Action</a>
2. Custom Scrollbars (SimpleBar)

Attach custom cross-browser slim scrollbars to any scrollable element simply by adding the data-simplebar attribute:

<div class="nd-sidenav-menu" data-simplebar style="max-height: 100vh;">
    <!-- Scrollable content -->
</div>
3. Phosphor Icons Integration

NahaAdmin bundles over 1,000+ vector Phosphor icons. You can use ph-bold, ph-regular, or ph-fill variants:

<i class="ph-bold ph-house fs-5"></i>
<i class="ph-regular ph-envelope"></i>
<i class="ph-fill ph-heart text-danger"></i>
4. Interactive Form Helpers

Built-in password reveal toggle script:

<div class="input-group">
    <input type="password" class="form-control password-toggle" placeholder="Password">
    <button class="btn btn-light toggle-password border" type="button">
        <i class="ph-bold ph-eye"></i>
    </button>
</div>
5. Custom CSS Helper Utilities
  • .border-dashed: Dashed border outline, ideal for dropzones and upload boxes.
  • .extra-small: Sets text size to 0.75rem for sub-labels and badges.
  • .timeline-simple: Vertical activity timeline component for audit logs and notifications.
