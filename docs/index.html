Introduction

Welcome to NahaAdmin! NahaAdmin is a clean, modern, and fully responsive free admin template built with Bootstrap 5.3, vanilla JavaScript, and customized CSS custom properties. It offers a premium, lightweight, and customizable base for building admin dashboards and SaaS management portals without heavy framework overhead.

Core Features:
  • Modern Tech Stack: Bootstrap 5.3, vanilla JS, custom CSS variables, and Phosphor Icons.
  • SPA-Like Transitions: Integrated page transition mechanisms using NProgress loading overlays.
  • Responsive Mini Sidebar: Collapsible sidebar with auto-expanding hover mode.
  • MIT License: Free for personal and commercial projects.

Getting Started

Set up NahaAdmin locally on your computer in minutes.

1. Cloning the Repository
git clone https://github.com/sepsu-dev/naha-admin.git
cd naha-admin
2. Local Run (Avoid CORS Issues)

Since the template utilizes modular JavaScript and dynamic AJAX elements, we recommend running it via a local development server (such as Live Server in VS Code) rather than opening the HTML files directly.

3. Creating a New Page

Always duplicate demo/blank.html or demo/starter.html as your blueprint. Place your custom views inside the <main> element. Sidenav links will be highlighted automatically by NahaAdmin's active routing script.

4. Folder Structure
naha-admin/
├── assets/         # App assets (images, custom CSS variables, custom JS)
│   ├── plugins/    # Vendor plugins (Bootstrap, Simplebar, ECharts, Select2)
│   ├── scripts/    # Custom JS (naha-admin.js)
│   └── styles/     # Global CSS (naha-admin.css)
├── demo/           # Suite of 53+ pre-designed HTML pages
└── index.html      # Landing page

Theme & Layout

NahaAdmin is built using CSS Custom Properties (Variables) inside assets/styles/naha-admin.css for fast, global theme changes:

:root {
  --nd-primary: #006fee;       /* Brand theme color */
  --nd-text: #11181c;          /* Base body text color */
  --nd-border: #e4e4e7;        /* Border color for lines/tables */
  --nd-radius: 10px;           /* Buttons & inputs radius */
  --nd-radius-lg: 16px;        /* Cards & modals radius */
}
Layout Class Toggles (Apply to <body>)
  • nd-nav-fixed: Fixed navbar at the top of viewport on scroll.
  • nd-sidenav-toggled: Collapses sidebar to mini-mode (which auto-expands on hover).
Sidebar State Persistence

The collapsed state of the sidebar is automatically saved inside the browser's localStorage under the key nd|sidebar-toggle to prevent layout shifts on page reload.

Custom Features & Utility

1. Excluding Links from SPA Transitions

NahaAdmin intercepts internal links for page-fade transitions. To bypass transitions (e.g. files, downloads, modals, or external links), add target="_blank", data-bs-toggle="...", or set the href to # or javascript:.

2. Custom CSS Utilities
  • .border-dashed: Dashed border styles, ideal for file uploads.
  • .extra-small: Renders font sizes at 0.75rem for timestamps/badges.
  • .timeline-simple: CSS vertical newsfeed timeline component.
3. Password Visibility Toggle
<div class="input-group">
    <input type="password" class="form-control password-toggle" placeholder="Password">
    <button class="btn btn-light toggle-password" type="button">
        <i class="ph-bold ph-eye"></i>
    </button>
</div>
