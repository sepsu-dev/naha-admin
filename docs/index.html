Introduction

Overview and core philosophy of NahaAdmin.

NahaAdmin is a modern, lightweight, and responsive free admin dashboard template built on top of Bootstrap 5.3, pure vanilla JavaScript, and modern CSS Custom Properties. Designed to give developers a clean, framework-agnostic starting point for web applications, SaaS dashboards, and control panels without the heavy overhead of complex build tools.

5 Dashboards

Default, Analytics, CRM, Ecommerce, and Finance pre-built dashboards.

4 Ready Apps

Interactive Inbox, Chat, Kanban Board, and File Manager modules.

56 Demo Pages

Complete suite of UI components, form controls, tables, and error pages.

Zero Build Step

Pure HTML5, CSS3, and JS. Ready to plug into any backend or serve statically.

What's Included:
  • Layout Flexibility: Full sidebar and collapsible mini sidebar with hover auto-expansion and localStorage state persistence.
  • SPA-Like Feel: Built-in smooth page transitions integrated with NProgress loading bar.
  • Phosphor Icons: Over 1,000+ modern icons across Bold, Regular, and Fill styles.
  • Advanced Data Tables: Basic responsive tables, DataTables, and Grid.js support.
  • Rich Forms: Select2 dropdowns, custom checkboxes/radios, Quill text editors, and client-side validation.
  • MIT Licensed: 100% free for both personal and commercial projects.
