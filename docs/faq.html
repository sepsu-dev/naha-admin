Frequently asked questions and answers about NahaAdmin.

Getting Started

A free, open-source admin dashboard template licensed under MIT. It is a clean suite of HTML, CSS, and JavaScript files built on top of Bootstrap 5.3 — not a bloated framework, not an npm component library. You drop it into your project, customize the markup to suit your application, and ship.

No build tools or bundlers are required! NahaAdmin is built with vanilla HTML, CSS Custom Properties, and JavaScript with jQuery. Open index.html directly in your browser, or double-click it in your file manager. No local server is required. Keep the project folders together; some examples need an internet connection for CDN assets.

NahaAdmin is built natively on Bootstrap 5.3.x. It leverages Bootstrap 5.3's modern utility classes, CSS Custom Properties, and responsive flexbox components.

Yes. The shared layout script requires the bundled jQuery. Load it before naha-admin.min.js and jQuery plugins such as Select2 and DataTables. Bootstrap 5 itself does not require jQuery.

Framework Integrations

  1. Copy the assets/ directory into your framework's public directory (e.g. public/ for Laravel/PHP or static/ for Django/Flask).
  2. Extract the top navigation bar, sidebar navigation, and footer from demo/starter.html into your template layout or blade partials.
  3. Render your dynamic server-side content directly inside the <main id="layoutSidenav_content"> container.

Customization & Theming

Edit --primary, --nd-primary-rgb, --nd-primary-dark, and --nd-primary-light in assets/styles/naha-admin.css, then copy its contents to assets/styles/naha-admin.min.css. See Theme & Layout for scope and examples.

Apply the class nd-nav-fixed to the <body> tag for fixed top navbar behavior. Add nd-sidebar-mini to enable the desktop icon rail, and nd-sidenav-toggled to start collapsed. The rail expands on hover or keyboard focus. Without mini mode, toggling hides it.

Troubleshooting

Styles, icons, or scripts are missing
Serve the repository root over HTTP. Inspect Network for 404s, check relative paths and filename case, and keep vendor files under assets/plugins/. Nested routes need adjusted asset paths.
Tables, editors, maps, or fonts fail offline
Some examples use CDNs, Google Fonts, remote images, or map tiles. Check connection and content security policy. Self-host required assets with their license notices for offline use; system fonts are the font fallback.
Sidebar or Bootstrap controls do not respond
Load jQuery before naha-admin.min.js and load bootstrap.bundle.min.js once. Check console errors, unique IDs, and matching data-bs-target values. Desktop sidebar preference uses nd|sidebar-toggle in localStorage; remove that key to reset it. Mobile starts closed; Escape closes the sidebar and restores toggle focus.
Shared CSS/JS edits do not appear
Edit the non-min source, then copy its contents to the matching .min.css or .min.js file. Pages load historical .min compatibility copies. Hard-refresh to bypass stale cache.
A copied component does not work
Copy its markup, page CSS, required vendors, and page initializer together. Preserve accessibility attributes and handler IDs, avoiding duplicate IDs. Check Getting Started for asset order and Browser Support for required APIs. Demo actions do not replace backend authentication, uploads, or persistence.
